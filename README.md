## 📚 Sobre

Exercícios e projetos desenvolvidos durante meus estudos na **[Alura](https://www.alura.com.br)**, nas áreas de **programação**, **banco de dados** e **análise de dados**. Cada arquivo é um exercício ou mini-projeto resolvido por mim, organizado por tema.

## 🗂️ Estrutura

```text
alura/
├── python/
│   ├── exercicios/
│   │   ├── matematica/            # 11 scripts: ângulos, hipotenusa, primos, tabuada, média de notas...
│   │   ├── conversores/           # 6 scripts: moeda, temperatura, valores, aluguel por km...
│   │   ├── texto-e-estruturas/    # 7 scripts: palíndromo, vogais, palavras, tuplas...
│   │   └── jogos-e-sorteios/      # 4 scripts: sorteio, senha, número aleatório...
│   ├── projetos/                  # 5 mini-projetos (veja abaixo)
│   └── trilha-de-dados/           # parte 2, 3 e 4 da trilha de dados
├── sql/
│   └── utilizando_like.sql        # consultas com LIKE
├── requirements.txt
└── LICENSE
```

## 🚀 Projetos em destaque

| Projeto | O que faz |
|---|---|
| [`cadastro_de_produtos.py`](python/projetos/cadastro_de_produtos.py) | Menu no terminal para cadastrar, listar e alterar o status de produtos |
| [`banco_clientes_contas.py`](python/projetos/banco_clientes_contas.py) | Classes `Cliente` e `ContaBancaria` (orientação a objetos) |
| [`jogo_numero_secreto.py`](python/projetos/jogo_numero_secreto.py) | Jogo em que o computador sorteia um número e você tenta acertar |
| [`lista_de_compras.py`](python/projetos/lista_de_compras.py) | Adiciona itens a uma lista de compras |
| [`calculadora_simples.py`](python/projetos/calculadora_simples.py) | Calculadora com as operações básicas |

## ▶️ Como executar

```bash
git clone https://github.com/luanbispo13/Alura.git
cd Alura

# dependência usada por python/exercicios/matematica/matematica.py
pip install -r requirements.txt

python python/projetos/cadastro_de_produtos.py
```

> Os scripts `cadastro_de_produtos.py` e `banco_clientes_contas.py` limpam a tela com `cls`, comando do Windows. No Linux/macOS, troque por `clear`.
